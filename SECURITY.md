# Security Policy — Address Resolution Platform

## Reporting Vulnerabilities

If you discover a potential vulnerability, injection risk, or denial-of-service vector in the Address Resolution Engine:

1. **Do not disclose the issue publicly.**
2. Report the findings via email to: **`sgupta.5545@gmail.com`**.
3. Include reproduction parameters, payloads, or benchmark metrics displaying the vulnerability.

We take security seriously and will investigate and patch critical flaws promptly.
